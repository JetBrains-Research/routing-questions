## Review Criteria

For each candidate, assign one label:

- `keep`: usable as a zero-shot greenfield sample with only light cleanup
- `rewrite`: useful idea, but must be rewritten into a self-contained prompt
- `reject`: not suitable

## Checklist

- Is this the first user request in a session?
- Does it ask for new code/project creation?
- Can the request be understood without the original repository?
- Does it avoid existing file names, failing tests, stack traces, PRs, issues, or prior turns?
- Is the expected output feasible for a small Python greenfield implementation?
- Can a human evaluator compare two solutions in about 30 minutes?
