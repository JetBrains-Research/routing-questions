Build a FastAPI app that has a few dummy endpoints (like GET /hello and GET /time) but with per-IP rate limiting implemented as a middleware using Redis. Each IP should be limited to 10 requests per minute using a sliding window counter in Redis. If the limit is exceeded return a 429 with a Retry-After header. Also expose a GET /rate-limit-status endpoint that returns the current request count and remaining quota for the calling IP. Use redis-py.
